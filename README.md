# PuffPop — Bubble Popcorn Drawing Pens

Professional product marketing site with add-to-cart and WhatsApp checkout.

## Run locally

```bash
npm install
npm run dev
```

Open **http://localhost:5177** (Aura stays on 5173)

## WhatsApp number

Edit `src/config.js` and set your number (digits only, country code, no +):

```js
export const WHATSAPP_NUMBER = '96170123456'
```

## Media

Product photos live in `public/media/` (same Bubble Popcorn Drawing Pens product as the Alibaba listing — Alibaba itself blocks scrapers, so images were pulled from matching retailer catalogs).
